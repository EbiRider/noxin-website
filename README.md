# نوکسین — وب‌سایت رسمی

وب‌سایت شرکت نوکسین، سازنده سامانه تخصصی طب کار **ژینوس**.

## تکنولوژی

- **Next.js 15** — App Router
- **TypeScript**
- **Tailwind CSS**
- فونت **Vazirmatn** — راست‌به‌چپ (RTL)

## شروع سریع

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) اجرا می‌شود.

## اسکریپت‌ها

| دستور | توضیح |
|-------|-------|
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت نسخه پروداکشن |
| `npm start` | اجرای نسخه پروداکشن |
| `npm run lint` | بررسی کد با ESLint |

## ساختار پروژه

```
src/
  app/
    layout.tsx       متادیتا و تنظیمات کلی
    page.tsx         صفحه اصلی
    globals.css      استایل‌های پایه و انیمیشن‌ها
  components/
    SplashScreen     اسپلش اسکرین با لوگو
    Navbar           نوار ناوبری چسبنده
    Hero             بخش معرفی اصلی
    Advantages       مزیت‌های ژینوس
    About            معرفی شرکت و آمار
    Features         امکانات سامانه
    TechStack        معماری فناوری
    Security         امنیت داده‌ها
    Contact          اطلاعات تماس و فرم دمو
    Footer           پاورقی
public/
  logoNoxin.svg      لوگوی کامل (اسپلش اسکرین)
  logoIcon.svg       آیکون برند (نوار ناوبری و پاورقی)
  favicon.svg        آیکون مرورگر
```
